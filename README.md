## Featured work

### [Chibcha Coffee & Roastery](https://chibchacoffee.com)
A café website and online shop built end to end as a freelance project, with a staff admin for products, inventory and orders.

**Built with:** Next.js, React, TypeScript, Supabase (PostgreSQL).

### [Azure Geometry Calculator](https://github.com/Bemir00/SBA_Azure)
A Flask web app backed by an Azure Functions REST API. The front end runs on Azure App Service, with deployment through GitHub Actions.

**Built with:** Python, Flask, Azure App Service, Azure Functions, GitHub Actions.

### [Travelling Salesman Problem](https://github.com/Bemir00/TSP_Genetic_algorithm)
A comparison of random search, nearest-neighbour greedy search and a genetic algorithm. The genetic algorithm achieved tours within 7.6% of the known optimum on berlin52 and 5.9% on kroA100.

**Built with:** Python, NumPy, pandas, Matplotlib.
